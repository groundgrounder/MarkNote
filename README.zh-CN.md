MarkNote 是一个**文件优先**的 Markdown 编辑器：不建私有笔记库，直接读写设备上任意目录的 `.md` 文件。在文件管理器里点击 `.md` 文件即可选择用 MarkNote 打开，改完自动保存回原位置。没有账号，不联网，也不申请存储权限——你的笔记始终只是你自己的文件。

## 下载

在 [Releases](https://github.com/groundgrounder/MarkNote/releases) 页下载最新 APK（`MarkNote-vX.Y.Z.apk`）。

- 支持 Android 8.0 及以上
- APK 不经过应用商店，首次安装时系统会要求你允许「安装未知来源的应用」
- **升级**：从 v1.1.1 起可直接覆盖安装；更早的版本需先卸载旧版

## 功能

**文件**

- 从文件管理器直接打开：在任意文件管理器里点 `.md` / `.markdown` 或纯文本文件，在系统「打开方式」里选 MarkNote 即可；重复打开复用同一个窗口
- 也可以用应用内的「打开文件」通过系统文件选择器读写**任意目录**（包括外置存储与云盘同步目录），不需要存储权限，改完自动写回原文件
- 原样保留文件编码：UTF-8（含/不含 BOM）、UTF-16 与 GB18030/GBK 都能正确读出，保存时按打开时的编码写回——GBK 的老笔记保存后仍是 GBK，不会被悄悄转成 UTF-8
- 最近打开列表：打开过的文件留在首页，重启手机后仍能继续编辑；条目可以移除（只移出列表，不删文件）；文件被移走或授权失效时会在列表里标红，点「重新授权」即可恢复
- 只读文件会明确提示：没有写权限时编辑器顶部会说明「修改不会被保存」，不会静默丢掉你改的内容
- 自动保存：停下打字 800 毫秒后自动存盘，退出编辑器或切到预览前也会强制保存；也可以在设置里改成手动保存（顶栏保存按钮在有未保存修改时高亮）

**编辑**

- 编辑区语法高亮：标题、加粗、斜体、删除线、引用、代码、链接、列表标记实时着色
- 符号化工具栏：H1/H2/加粗/斜体/删除线 + 引用/列表/链接/代码/分割线，常驻键盘上方，选中文字后点按钮直接包裹
- 搜索替换：命中计数（n/m）、循环跳转高亮、单个替换与全部替换
- 撤销/重做：顶栏两个按钮。连续输入会并成一步（停顿即断开），工具栏插入与「全部替换」各自单独成步；撤销后光标回到改动处，没得撤时按钮自动置灰
- 大纲导航：横屏/平板从右侧滑出面板，窄屏为底部弹层，点击直接跳到该标题（预览态同样可调出）
- 字数统计：顶栏实时显示「N 字 · M 行」

**预览**

- 一键切换编辑/预览：支持 GFM 表格（表头、斑马纹、列对齐）、删除线、可点击链接
- LaTeX 公式：`$$…$$` 与单个 `$…$` 都渲染为行内公式，独占一行的 `$$` 渲染为居中的块级公式——矩阵（`\begin{pmatrix} a & b \\ c & d \end{pmatrix}`）、分式、积分、求和、希腊字母等常见写法都可用。公式取主题的文字颜色，深色主题下不会变成黑字黑底；字号跟随预览字号。分隔符按 Pandoc 的规则判定，「从 $5 到 $10」「$ x$」「$x $」「$x$1」都保持原样。渲染不出来的公式会以错误色加描边框显示公式源，而不是无声地留成普通文字
- 预览里也能搜索、也能调大纲：搜索跑在**渲染结果**上（所见即所搜），命中逐个高亮、当前命中实心高亮并自动滚入视野，带 n/m 计数与上下跳转；大纲点击直接把正文滚到对应标题。预览是只读视图，所以搜索面板不提供替换
- 图片显示：相对路径图片按**文档所在文件夹**解析（`..` 可正常上行，与 Markdown 惯例一致），首次按引导条授权一次即可——请选**同时包含文档与图片**的文件夹（授权长期有效）；图片落在授权范围外或找不到时，会在原位置显示「已授权文件夹里没有这张图」的占位，而不是静默消失；支持 `content://`、`file://`、base64 内嵌图；大图自动降采样防止内存不足

**界面与适配**

- Material You：Android 12+ 动态取色，浅色/深色可跟随系统或手动锁定，边到边布局
- 平板/横屏双栏：宽屏自动切换为左栏文件列表 + 右栏编辑器，旋转实时切换；侧栏可收起为窄条
- 设置页：主题模式、界面语言、编辑器与预览字号独立调节、自动保存开关、版本信息
- 启动图标支持 Android 13+ 主题图标，跟随系统的单色化设置

## 使用提示

- **预览里搜不到 `$` 或 `$$`**：公式分隔符在渲染时会被去掉，所以预览里搜不到，编辑器里能搜到；公式内部的文字照常可搜
- **图片不显示**：相对路径图片按文档所在文件夹解析。若提示「已授权文件夹里没有这张图」，请重新授权**同时包含文档与图片**的那个文件夹——只授权文档所在的文件夹时，图片在它之外就会失败
- **从聊天记录、「打开方式」进来的文件，过一会儿就打不开了**：这类外部应用传入的文件通常拿不到长期授权。MarkNote 在打开时会立即提示，按提示用系统文件选择器重选一次同一个文件，就能拿到长期授权，之后从最近列表也能直接打开
- **为什么没有 Ctrl+Z 快捷键**：文本框有焦点时字母按键会先交给输入法，Gboard 等输入法自带逐字符撤销会吃掉这个组合键，应用收不到。撤销请用顶栏按钮
- **公式显示成错误色加方框**：整条公式里出现了一个无法识别的命令（如 `\zzzz`），整条都不会渲染，改掉它即可。注意公式字库不含中文，`\text{中文}` 渲不出来——中文请写在公式外面

## 界面语言

内置 **4 种界面语言**：简体中文、繁體中文、English、Latina。默认跟随系统，也可以在设置里手动指定，切换立即生效并保留当前正在编辑的文档；未内置的语言（日语、法语、德语等）显示英文。最近文件列表的时间格式也跟随语言。

Android 13 及以上还有一条系统入口：可以在系统「设置 → 应用 → MarkNote → 语言」里直接改，与应用内的选项双向同步。
