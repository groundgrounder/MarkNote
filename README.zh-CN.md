## 这是什么

一个手机上的 Markdown 编辑器，写笔记、写日记、改文档都行。

- 手机上写、电脑上接着改：它编辑的是手机里已有的 `.md` 文件，改完自动存回原处，你原来怎么备份、怎么同步都照旧
- 写起来顺手：语法高亮、一键预览，表格、公式、图片都正常显示
- 免费开源，没有账号，不联网，也不要存储权限

## 下载

在 [Releases](https://github.com/groundgrounder/MarkNote/releases) 页下载最新 APK（`MarkNote-vX.Y.Z.apk`）。

- 支持 Android 8.0 及以上
- 应用不在应用商店上架，首次安装时系统会要求你允许「安装未知来源的应用」
- **升级**：从 v1.1.1 起可直接覆盖安装；更早的版本需先卸载旧版

## 功能

**打开与新建**

- 打开：在文件管理器里点一份 `.md`、`.markdown` 或纯文本文件，选「用 MarkNote 打开」
- 新建：点右下角的「＋」。在文件夹档里直接建在当前目录，长按这个按钮则新建文件夹；在最近文件档会先问放到哪
- 能打开的是 Markdown 与纯文本；图片、压缩包、PDF 这类二进制不会出现在列表里

**文件夹**

- 侧栏切到「文件夹」档，授权一个文件夹，之后直接在里面挑文档，也能进子目录
- 长按条目唤出菜单：重命名、删除，文件还有「在新窗口打开」
- 长按右下角的「＋」，在当前目录新建文件夹
- 删除是真删，不进回收站，确认框里会写明
- 名字以 `.` 开头的文件与文件夹（`.git`、`.obsidian`）默认不显示，设置里打开「显示隐藏文件」就能看到
- 从这里打开的文档，会把该文件夹当作图片所在的位置

**最近文件**

- 打开过的文档留在首页，重启后照样接着写
- 每条尾部有个「×」，点一下移出列表，文件本身不动
- 文件被移走或读不了会标红，点开按提示重新授权即可

**编辑**

- 语法高亮：标题、粗体、斜体、删除线、引用、代码、链接各有配色
- 工具栏：标题、粗体、斜体、引用、列表、链接、代码、分割线一键插入，就贴在键盘上方；选中文字后一点就包好
- 撤销 / 重做：顶栏两个按钮。连续打字算一步，插入和「全部替换」各算一步；没得撤时按钮变灰
- 回车续列表：`-`、`1.`、`>`、`- [ ]` 都接着上一行的写法写，任务项续出来是未勾选；空条目上再按一次回车就结束列表
- 缩进：Tab / Shift+Tab 缩进或反缩进，选中多行时整块处理
- 外接键盘：Ctrl+S 保存、Ctrl+F 查找、Ctrl+B / Ctrl+I 加粗斜体、Ctrl+Z 撤销、Ctrl+Shift+Z（或 Ctrl+Y）重做。软键盘发不出这些组合键，手机上用顶栏按钮
- 顶栏常显「N 字 · M 行」

**查找与大纲**

- 搜索替换：显示「第几处 / 共几处」，可循环查找，能只换这处，也能一次全换
- 预览里也能搜：搜的是你看到的内容，命中逐个高亮并自动滚进视野；预览只读，没有替换
- 大纲：横屏和平板从右侧滑出，窄屏从底部弹出，点标题直达

**预览**

- 编辑 / 预览一键切换，表格、删除线、可点击的链接都正常显示
- 任务列表显示成复选框；正文里的裸链接（`https://…`）直接成链接，点开即用
- 文档内跳转：点 `[文字](#标题)` 直接滚到那一节，找不到时提示一句；脚注写法（`[^1]` 和它的定义行）照原样显示
- 公式：`$…$` 行内显示，单独一行的 `$$` 居中；矩阵、分式、积分、求和都能写。单个或不成对的 `$` 原样保留，「从 $5 到 $10」不会被当成公式
- 图片：相对路径按**文档所在的文件夹**找（`..` 可往上一层），按提示授权一次该文件夹，之后一直有效
- 图片在授权范围外或找不到时，会在原处显示一行说明；内嵌的图片同样能显示，过大的会自动缩小

**保存**

- 自动保存：停手 800 毫秒后写回，离开编辑器或切到预览前也会存一次
- 也可以改成手动：设置里关掉自动保存，顶栏出现保存按钮，有未保存改动时高亮；这时离开编辑器会先问一句（保存 / 不保存 / 留在编辑器）
- 不改编码：UTF-8、UTF-16、GBK 都能读，存回时还用原编码——GBK 老笔记存完还是 GBK
- 编辑器顶部会提醒三种情况：存不下去（没有写权限，或文件已不在）、文件是只读的、文件没有长期授权。每条都带「重新授权」

**多窗口**

- 一块窗口一份文档：可同时开好几块（系统分屏、平板桌面窗口），各写各的互不影响
- 再开一块：长按最近列表里的文件，选「在新窗口打开」
- 走「在新窗口打开」时，同一份文件不会再开第二个编辑器，免得两边各改各的互相覆盖
- 返回键仍是回到文件列表；关窗口用系统的最近任务

**界面与语言**

- 跟随壁纸取色（Material You，Android 12+），浅色 / 深色可跟随系统或自己锁定
- 平板和横屏自动变双栏：左边文件列表、右边编辑器；左侧栏可收成窄条
- 界面语言四种：简体中文、繁體中文、English、Latina。默认跟随系统，也能在设置里切换，正在编辑的文档不会丢
- 没内置的语言显示英文；Android 13+ 还能在系统「设置 → 应用 → MarkNote → 语言」里改
- 设置页：主题、语言、编辑器与预览字号（各自独立）、自动保存、文件夹浏览是否显示隐藏文件、外部文件的权限提示、版本信息
- 图标跟随系统的主题图标设置（Android 13+）

## 几点说明

- 从别的应用（文件管理器、聊天、邮件）打开的文件拿不到长期授权，MarkNote 关掉后就打不开了。按编辑器顶部的提示重选一次该文件，就能长期使用；打开时那个说明弹窗可以勾「不再提示」，设置里能改回来
- 图片要授权文件夹：请选**同时包含文档和图片**的那个；只授权文档所在的文件夹时，图片在它之外就会失败
- 预览里的搜索搜的是显示后的文字，所以 `$`、`$$` 这类公式标记在预览里搜不到（编辑器里能搜），公式里的文字照常能搜
- 公式里有一个认不出来的命令（如 `\zzzz`），整条会显示成加框的提示，改掉它就行。公式字库不含中文，`\text{中文}` 显示不出来，中文请写在公式外
- 输入法自己也带撤销：按 Ctrl+Z 若只退了一个字，那是输入法做的，顶栏按钮才走 MarkNote 自己的撤销历史
- 卸载重装，或在系统里撤销了授权，文件夹都要重新选一次

### v1.1.0

- 重做应用图标：Markdown「M↓」记号重画。M 笔画加粗，改成平口端点加直角接角（顶角是方的、中间 V 是尖的），不再是一团圆头涂鸦；下箭头改为与 M 同高同重、共用上沿与基线，此前它比 M 矮一截、头还偏大

### v1.1.4

- 撤销不再吞掉工具栏插入之后输入的内容：按完 H1 再打字不会并成一步（否则撤销一次会把两件事一起退掉）
- 修复：重新进入文档时，可能把刚敲进去的字整份覆盖掉
- 大纲现在同时认 `~~~` 与三个反引号两种围栏代码块，且只有同种字符、长度不短于开头才算闭合——此前 `~~~` 块里的 `#` 会漏进大纲，块内出现的三个反引号又会把代码块提前闭合

- 带 BOM 的文件，最近列表的摘要不再以一个看不见的空白字符开头
- 最近打开列表最多保留 100 条（超出按打开时间淘汰最旧的），列表不再越用越慢
- 另外两处边界修复：某些存储位置写入被截短时，不会再在文件里留下旧内容的尾巴；最近列表的记录损坏时会先备份原文，而不是直接把列表清空

### v1.2.0

- 预览支持 LaTeX 公式：`$$…$$` 渲染为行内公式，独占一行的 `$$` 渲染为居中的块级公式。矩阵、分式、积分、求和、希腊字母都能用；公式取主题的文字颜色，深色主题下依旧清晰；字号跟随预览字号

### v1.2.1

- 大纲跳转现在知道单 `$` 分隔符在渲染时同样会被剥掉，跳转到含单 `$` 公式的标题能精确落位
