## 🌟 为什么选择 MarkNote？

市面上大多数 Markdown 应用都会强制你将文件导入数据库，或者强制绑定自家的云同步服务。MarkNote 走了一条完全不同的路：**它只负责编辑手机中原汁原味的文件。**

* **数据自主，无平台绑定：** 直接编辑手机里已有的 `.md` 或 `.markdown` 文件，修改即时写回原处。你可以继续使用原有的同步工具（如 Syncthing、Git、Obsidian Sync、坚果云等）进行备份和多端同步。
* **极致隐私，轻量安全：** 无需注册账号、不含广告、不联网、不收集任何隐私数据。得益于 Android 现代的存储访问框架（SAF），它甚至**不需要任何文件读写（存储）权限**。
* **功能完备，体验流畅：** 语法高亮、快捷工具栏、LaTeX 数学公式、GFM 表格渲染、本地相对路径图片、多窗口分屏，为你提供极佳的输入和阅读体验。

## ✨ 核心功能

### 📂 文件与工作区管理
* **直接打开编辑：** 支持在系统文件管理器中点选任何 `.md`、`.markdown` 或纯文本文件，直接选择「用 MarkNote 打开」并开始编辑。
* **工作区文件夹映射：** 侧边栏支持切到「文件夹」页，只需单次授权一个本地文件夹，即可直接在应用内浏览子目录、挑拣和编辑文档。
* **应用内本地管理：** 支持在授权的工作区中新建文件或文件夹、重命名、直接删除（长按对应条目即可唤出操作菜单）。
* **最近打开记录：** 首页自动保留最近打开的文档，重启应用也依然在列。点击条目右侧的「×」可将其从历史列表中移除，**完全不影响文件本身**。

### 🖋️ 流畅的编辑体验
* **实时语法高亮：** 标题、粗体、斜体、删除线、引用、代码块、超链接等均有清晰美观的配色高亮。
* **快捷输入工具栏：** 贴心地紧靠在软键盘上方，支持一键插入标题、加粗、斜体、引用、列表、链接、代码、分割线。选中文字后点击，即可自动用标记符号包好。
* **智能列表续写：** 键入回车时，自动延续 `-`、`1.`、`>`、`- [ ]` 等列表前缀（有序列表会自动累加序号，任务列表默认续出未勾选状态）。在空行上再次按回车，即可干净地结束列表。
* **快捷缩进控制：** 软键盘状态下支持点击工具栏，或外接键盘下按 `Tab` / `Shift+Tab` 来实现整行或选中多行的缩进/反缩进。
* **颗粒度撤销重做：** 顶栏配备专门的「撤销/重做」按钮。应用会智能识别输入停顿（600 毫秒），将连续打字合并为一步，确保撤销时不会一次性抹掉一大段话。
* **硬件键盘快捷键：** 深度适配外接实体键盘，支持 `Ctrl+S`（保存）、`Ctrl+F`（查找替换）、`Ctrl+B`/`Ctrl+I`（加粗/斜体）、`Ctrl+Z`/`Ctrl+Y`（撤销/重做）等标准快捷键。
* **实时字数统计：** 编辑器顶栏常驻显示当前的字数与行数（`N 字 · M 行`）。

### 📖 GFM 预览与 LaTeX 公式
* **标准 GFM 渲染：** 编辑与预览一键切换，完美渲染 Markdown 表格（含表头、斑马纹、列对齐）、可直接点击勾选的任务列表框、裸链接自动高亮。
* **LaTeX 数学公式：** 完美支持单 `$` 行内公式（遵循 Pandoc 判定规则，避免像「$5 到 $10」被误判）与独立双 `$$` 居中块级公式。公式颜色自适应主题，深色模式下同样清晰易读。
* **Obsidian 式相对图片：** 支持如 `../img/pic.png` 这样的相对路径图片引用。只需在应用首次提示时授权一次这些图片所在的文件夹，它们就能在预览中完美显示，完美兼容桌面端 Obsidian 等本地库。
* **内跳转与脚注：** 点击 `[文字](#标题)` 可直接在文档预览内精准滚动跳转。完整支持 Markdown 标准脚注（`[^1]`）语法。

### ⚙️ 保存、编码与界面个性化
* **双保存模式：** 
  * *自动保存：* 停止输入 800 毫秒后自动将改动写回磁盘，离开编辑器或切换到预览前也会自动存盘。
  * *手动保存：* 可以在设置中关闭自动保存，此时顶栏会出现保存按钮（有未保存改动时高亮）。带改动离开时会弹窗确认（保存 / 不保存 / 留在编辑器）。
* **原始编码保护：** 自动探测并沿用文件的原始编码，支持 UTF-8（含/不含 BOM）、UTF-16、GBK/GB18030。哪怕是 GBK 编码的老笔记，编辑保存后依然是原汁原味的 GBK，不担心乱码。
* **多窗口并行编辑：** 在分屏模式或平板电脑上，允许同时开启多个 MarkNote 窗口，各自编辑不同的文档。同一份文件禁止重复打开，避免冲突覆盖。
* **Material You 动态主题：** Android 12+ 手机可自动根据系统壁纸动态提取配色。浅色/深色主题可设为跟随系统或手动锁定。
* **平板与宽屏优化：** 横屏或平板下自动采用双栏布局，左侧为文件/大纲树，右侧为编辑器，最大化利用屏幕空间。
* **多语言界面：** 提供简体中文、繁體中文、English 及拉丁语（Latina）四种界面语言。

## 💡 使用小贴士

* **外部文件的长期授权：** 从第三方应用（如聊天软件、外部文件管理器等）直接拉起 MarkNote 打开的文件，通常只拥有系统临时授权，MarkNote 退出后就无法重新读取。建议根据编辑器顶部的黄色横幅提示，重新选择一次该文件以获取长期授权，即可持久保留在首页的「最近文件」中。
* **显示相对路径图片：** 想要显示文档内的相对路径图片，请务必在弹窗中授权**同时包含该文档和图片文件夹**的父级文件夹。如果只授权了文档所在的文件夹，而图片存放在同级的 sibling 目录中，预览将无法显示。
* **LaTeX 公式报错：** 如果公式里写了认不出来的命令（如 `\zzzz`），预览中整条公式会以红色的细框标出，方便你找出是哪一条公式写坏了。另外公式字库不含中文字符，请避免在数学公式内部写入中文。
* **虚拟键盘的撤销历史：** 如果你使用的是手机虚拟键盘，按下键盘自带的键盘撤销可能只会一次回退一个字，这是输入法自己的机制。想使用应用内智能的分段撤销，请点击 MarkNote 顶栏的撤销和重做按钮。
* **权限重置：** 卸载重装应用，或者在 Android 系统设置中清除了 MarkNote 的授权，都需要重新在应用内选择并授权一次你的工作区文件夹和图片文件夹。
